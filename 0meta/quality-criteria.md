# 笔记深刻度质量标准（当前版本参考）

> 目的：给生成 AI 和「reviewed」人工抽检关卡一个可操作的判断框架。不是「写得漂不漂亮」，而是「读完之后，读者是否获得了一个更锋利、也更要求他/她的心智模型」。

## 「深刻 / very ok」的核心感受（目标）
- 读者会产生「原来如此，但我之前一直用更舒服的方式对自己撒谎」的轻微刺痛或震动。
- 笔记本身值得反复读（不是只用来查「那章讲了什么」）。
- 即使读者不同意，也能清楚地看见「如果我认真接受它，我必须在哪些地方改变自己」。
- 它忠实于原书，却比原书更「能用」——因为它把张力、代价、边界一起交到了读者手里。

## 八条可检查标准（带常见问题 vs 当前目标）

1. **张力可见度**
   - 常见问题：要点和核心观点像「作者说了 A、B、C」，没有看见作者在和什么过不去。
   - 当前目标：每一章、每一个核心观点都明确指出「这里在挑战读者/前章/主流假设的什么」。

2. **读者抵抗点被命名**
   - 常见问题：点评只说「这很重要」「这揭示了……」。
   - 当前目标：每条关键摘录的点评都同时回答「它挑战了什么默认假设」和「实践/接受它时人最常见的两种内在抵抗或误用是什么」。

3. **章与章之间的逻辑必然性（而非并列）**
   - 常见问题：「作用」或「小结」写成「本章为后文做了铺垫」。
   - 当前目标：「本章把前章的逻辑推到这个地步，使得后文**必须**回答 X，否则作者的整个论证就崩了」；或者「这里作者反转了自己前面的说法，代价是……」。

4. **启示必须是可演绎的后果，而不是外挂建议**
   - 常见问题：「可落地的启示」和书本身关系松散，像从别的成功学书里抄来的。
   - 当前目标：每条启示都能清晰回溯到书中至少一个具体机制或张力，并且写出「在什么情境下按这个逻辑必然会这样」。

5. **代价与「毒」被诚实呈现**
   - 常见问题：只写正面价值 + 温和的「局限」。
   - 当前目标：明确写「如果你认真服用这本书的药，它会要求你放弃/承受什么」；以及「按它自己的逻辑，如果被误读或用在错误地方，会系统性地产生什么坏结果」（药与毒）。

6. **统一意象 / 机制被抓住并被推到边界**
   - 常见问题：只罗列多个观点，缺少「这本书其实只有一件事在反复说」。
   - 当前目标：reduce 里必须有一个小节专门处理「全书最统一的意象/机制是什么？它的极限在哪里？」

7. **对浓缩、象征、经典文本的尊重（不提前现代化）**
   - 常见问题：把内丹、斯多葛、浓缩格言直接翻译成「注意力管理」「正面思考」「设定边界」。
   - 当前目标：保留原文的象征系统和身体-心性-宇宙对应；在必要时说明「这里如果翻译成现代语言会失去什么」。

8. **可重读性（而非可检索性）**
   - 常见问题：笔记写得像好的讲义或 wiki，信息密度高但没有「刺」。
   - 当前目标：哪怕只读 3 分钟，读者也会觉得「这几句话我得再看一遍」，而不是「我已经知道大概讲了什么，可以关了」。

## 微型前后对比（从本库真实样本简化）

**例1 · 关键摘录点评**
- v1 常见：「这个实验说明锚定很危险，专业人士也不能幸免。」
- 当前目标：「它挑战了『专业训练会让人更理性』的默认假设。实践中最大的抵抗是：我们会把『我没感觉被影响』当成『我真的没被影响』的证据，从而主动关闭系统 2 的对抗性搜索。」

**例2 · 可落地的启示**
- v1 常见：「在重要决策时要慢下来，检查自己是不是被锚定了。」
- 当前目标：「当任何公开数字（报价、KPI、专家预测、别人说『别人都这么做』）出现时，必须主动去搜集『如果这个数字不存在，我会怎么想』的对抗性记忆。这不是慢下来，而是主动破坏系统 1 已经激活的相容样本。」

**例3 · 局限/毒**
- v1 常见：「本书案例多为咨询经验，系统性论证较少。」
- 当前目标：「当『这是他的课题』从一个要求人更真实在场的工具，退化成一句快速切割责任、逃避『我其实很在乎』的借口时，关系就会从互相负责的复杂系统，退化成我只管我自己的原子化交易——而这恰恰是作者最想拆掉的那种现代幻觉的另一种形式。」

## 人工抽检（reviewed 关卡）简易 checklist
- [ ] 这份笔记读完后，我是否对原书产生了新的、带刺的理解，而不是「大概知道讲了什么」？
- [ ] 里面是否有 1–3 处让我产生「我以前就是这么对自己/对别人撒谎的」的具体联想？
- [ ] 启示和张力是否能回溯到书中具体机制？
- [ ] 「药与毒」和「统一机制的极限」是否被诚实处理了？
- [ ] 如果我只保留这本书的 3 句话，我会选哪 3 句？它们是否已经在这份笔记里被足够锋利地呈现？
- [ ] 对于内丹/哲学/格言类：象征系统是否被粗暴地心理学化了？

通过以上任意 4 条，即可考虑进入 reviewed。

## 与提示词版本的关系
当前版本的提示词（map.v1.md / reduce.v1.md / highlights.v1.md）已在原有基础上强化了张力可见、读者抵抗点命名、代价与毒诚实呈现、以及可重读的刺的要求。

本文件与 0meta/prompts/ 下的提示词文件一起构成当前工作的判断标准。所有示范笔记的 prompt_version 已记录为 map.v1+reduce.v1。
