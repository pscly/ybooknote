# Highlights 提示词 · v1（摘录与金句）

> 用途：跨全书挑选最有价值的原文摘录与金句，产出 `highlights.md`。
> 输入：各章「关键摘录」与原文。
> 输出：写入 `1notes/<书>/highlights.md`（保留 frontmatter）。

## 规则
- 只收**原文片段**（可用省略号压缩），不收你的转述。
- 每条标注定位线索（章/小节），并配一句「为何值得记」。
- 宁缺毋滥：优先收可独立成立、可被引用的句子；去重近义。
- 按主题或按章顺序分组，便于检索。

## 结构
```
# <书名> · 摘录与金句

## <主题或第N章>
> 「<原文金句>」—— <定位>
（一句点评：为何重要 / 可用在何处）

> 「<原文金句>」—— <定位>
```

## 质量自检
- 每条都能在原文找到吗？
- 脱离上下文是否仍有价值？
- 是否覆盖了全书不同部分，而非集中在前几章？
