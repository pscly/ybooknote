# Highlights 提示词 · v1（摘录与金句，极致筛选）

> 用途：跨全书挑选最有价值的原文摘录与金句，产出 `highlights.md`。
> 输入：各章「关键摘录」与原文 + 当前版本的点评。
> 输出：写入 `1notes/<书>/highlights.md`（保留 frontmatter）。

## 核心规则
- 只收**原文片段**（可用省略号压缩），不收你的转述。
- 宁缺毋滥：优先收可独立成立、可被反复引用的句子；去重近义。
- 按主题或按章顺序分组，便于检索。
- **当前要求**：每条金句必须同时具备「照见力」和「危险性」。
  - 照见力：在读者某个具体的生活或心智场景里，它会让之前模糊的东西突然清晰。
  - 危险性：它很容易被读者用舒服的方式误读、稀释或武器化。

## 结构
```
# <书名> · 摘录与金句

## <主题或第N章>
> 「<原文金句>」—— <定位>
（生活照见场景：它会在读者什么时候、什么具体情境里突然刺中人？  
它会在这里暴露读者什么盲点？  
边界/风险：读者最容易在这里把它用错或用浅。）

> 「<原文金句>」—— <定位>
...
```

## 质量自检
- 每条都能在原文找到吗？
- 脱离上下文是否仍有力量？是否只在「听起来高级」？
- 是否覆盖了全书不同部分，而非集中在前几章？
- 每条的「生活照见场景 + 盲点 + 边界/风险」是否具体到「我能想象一个具体的人在具体的一天里被这句话打脸」？还是又变成了「这句很有哲理」？
- 整份 highlights 读完后，读者是否会产生「这些句子放在一起，形成了一面我不敢长时间直视的镜子」的感受，而不是「这里有不少好话我可以抄下来」？

## 当前版本要求（升级说明）
- 数量可以比之前更少，但每条的「解说」必须更重（场景 + 盲点 + 风险）。
- 优先选择那些「作者自己可能都没完全展开、但后果极其严重」的句子，而不是最漂亮或最常被引用的。
- 对于内丹、斯多葛、浓缩经典类书籍，特别保留那些「字面很美、实操极难、误用极易」的句子，并把「极难」和「极易」在注释里说清楚。

## 输出要求
- 更新 frontmatter prompt_version 为 highlights.v1。
- 保留 NAV 注释。
- 分组标题可以用章名或主题，优先让读者快速定位到「我现在正卡在这个场景」。
- 解说部分控制在 2–4 行，具体、锋利、不油。
