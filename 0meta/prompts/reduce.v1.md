# Reduce 提示词 · v1（全局缝合）

> 用途：汇总各章「在论证链中的作用」+ 末章滚动摘要，重建全书脉络，产出 `summary.md`。
> 输入：`1notes/<书>/chapters/*.md` 的「作用」段与要点。
> 输出：写入 `1notes/<书>/summary.md`（保留并更新其 frontmatter）。

## frontmatter（保留既有字段，补充）
```yaml
title: <书名>
author: <作者>
book_id: <book_id>
status: drafted        # 由 status.py 推进，这里同步写入
tags: [<3–6 个主题标签>]
created: <YYYY-MM-DD>
prompt_version: map.v1+reduce.v1
```

## 正文结构
```
# <书名> · 全书总览

## 一句话核心
<把全书压缩成一句话>

## 论证主线
<3–6 段或要点：作者从哪里出发、用什么搭建论证、推到什么结论。体现递进与转折。>

## 结构脉络
<分部分/分章群说明全书骨架，章节如何呼应、铺垫、收束>

## 核心观点
- （5–10 条提炼，带一句展开）

## 可落地的启示
- （3–6 条：读者能拿来用的东西）

## 适合谁 / 局限
<谁该读、读它解决什么问题；以及本书或本总结的局限>
```

## 质量自检
- 是否重建了**全局脉络**，而不只是把各章要点堆叠？
- 标签是否准确、可用于检索与 README 归类？
- 有没有把分块过程中丢失的「章节间关系」补回来？
