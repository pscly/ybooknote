# Map 提示词 · v1（分块精炼 + 深度挖掘）

> 用途：对**单章**纯文本精炼。每章独立产出一份章节笔记，并维护滚动摘要传递给下一章。
> 输入：`1books/<书>/.cache/chapters/NN.txt` 一章正文 + 截至上一章的「滚动摘要」。
> 输出：写入 `1notes/<书>/chapters/NN-<短标题>.md`。

## 核心原则
- 只读不改原文；忠实于作者，不臆造、不脑补数据与结论。
- 摘录必须是原文片段（可压缩省略号），并标注定位（小节标题或段落线索）。
- 区分「作者观点」与「你的转述」，不要把概括写成原文引用。
- **当前要求**：笔记本身必须让读者产生「原来如此但我之前没看见」的感受，而不是「这章大概在说什么」的总结。

## 处理规则
- 要点（3–7 条）必须覆盖本章**核心论证、结论以及最强的张力/反常识点**。不要只列「作者说了什么」，而要让读者一眼看到「这里在和什么常识/前章/读者默认信念过不去」。
- 关键摘录的**点评必须回答两个问题**：
  1. 它直接挑战了读者什么默认假设或舒适区？
  2. 实践/接受它时，读者最常见的两种误用或内在抵抗是什么？
- 「在全书论证链中的作用」升级为「辩证位置」：明确写出
  - 本章继承或反转了前一章（或前几章）的什么；
  - 它此刻对读者心智/性格提出的**非可选要求**是什么；
  - 它为后文必然埋下什么必须回答的问题（让后文不是随意展开，而是逻辑必然）。
- 滚动摘要（传给下一章）要携带**累积的 stakes 和开放问题**，而不仅是「到本章为止的主线进展」。
- 宁缺毋滥。淡化泛泛而谈的「重要性」，强化「它在这里的代价与张力」。

## 章节笔记结构（写入 chapters/NN-*.md）
```
# 第 NN 章 · <章节标题>

## 要点
- （3–7 条，覆盖本章核心论证、结论 + 最强的张力/反常识点。让读者看见「这里在和什么过不去」。）

## 关键摘录
- 「<原文片段>」—— <定位线索>
  - 点评：（必须包含：它挑战了读者什么默认假设？实践时最常见的两种抵抗/误用是什么？）

## 在全书论证链中的作用（辩证位置）
<本章承接/反转前文什么；此刻对读者提出什么具体、非可选的心智或品格要求；它为后文必然埋下什么必须回答的问题。1–3 句，精准。>

## 滚动摘要（传给下一章）
<2–4 句：到本章为止的主线进展 + 累积的 stakes / 开放问题 / 读者此刻最可能卡住的地方，供下一章 Map 时作真正有用的上下文>
```

## 质量自检
- 要点能否脱离原文独立读懂？是否只在「复述」而不是「揭示张力」？
- 摘录是否真出现在本章？定位是否可核对？
- 每条关键摘录的点评是否同时回答了「挑战了什么假设」和「实践时的抵抗点」？
- 「作用」是否体现了与相邻章节的**继承/反转/必然要求**关系，而非孤立复述或泛泛「为后文做铺垫」？
- 滚动摘要是否给下一章提供了**可用的 stakes 和问题**，而非空洞进度条？

## 当前版本要求（升级说明）
- 从「忠实复述 + 基本可操作」升级到「揭示张力 + 让读者看见自己会如何抵抗 + 建立章与章之间的逻辑必然性」。
- 点评长度可以稍长，但必须具体（避免「这很重要」「这揭示了人性」这类空话）。
- 保留所有原有结构和 frontmatter 字段，只在内容深度上加码。

## 特殊体裁指导（内丹、经典哲学、浓缩格言类）
- 保留象征系统的内在一致性与身体-心性-宇宙的对应关系。不要过早把「回光」「元神」「魂魄」翻译成「注意力训练」「潜意识」「正面思维」，除非原文作者已经在做这个桥接。
- 对于极短或格言式的章节，宁可少写几条极精准的「张力点 + 要求」，也不要为了凑 3–7 条而稀释。
- 滚动摘要要特别注意把「这一句/这一象在整个修行/伦理体系里的位置」传递下去，避免下一章把前文当孤立的技巧。

## 输出要求
- 严格按照上述结构输出完整 Markdown。
- 章节标题使用原文或合理简短形式。
- 文件名保持 `NN-短标题.md` 约定。
- 在文件顶部保留或复制 NAV 注释块。
