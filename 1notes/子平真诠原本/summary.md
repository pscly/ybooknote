# 子平真诠原本 · 全书总览

## 一句话核心

本书以「月令用神」为枢轴，系统阐述子平八字命理的理论体系，是清代命学正宗集大成之作。

## 全书理论框架

全书共四十七篇，逻辑递进，层次分明：

1. **本体论基础**（篇一至七）：从天地阴阳出发，论十干十二支的阴阳属性、五行生克原理、阴阳生死（十二长生）、十干配合性情与刑冲会合。这是整套理论的宇宙论根基。

2. **用神核心论**（篇八至十七）：以「月令用神」为全书核心命题，详论用神的寻取、成败救应、变化、纯杂、格局高低、因成得败/因败得成、配气候得失、相神紧要、杂气取用、墓库刑冲。这是全书理论的骨干。

3. **吉凶辩证论**（篇十八至二十八）：阐明四吉神（财官印食）能破格、四凶神（煞伤枭刃）能成格的辩证关系，论生克先后之吉凶、星辰无关格局、外格用舍、六亲宫分与妻子论、行运原理。

4. **时说纠谬**（篇二十九至三十）：批驳当时流行的拘泥外格、以讹传讹之说，重申月令为本的正确方法论。

5. **十格专论**（篇三十一至四十七）：依次论正官、财、印绶、食神、偏官、伤官、阳刃、建禄月劫、杂格，每格均含「取格」与「取运」两部分，附大量历史命例佐证。

## 核心概念

| 概念 | 含义简述 |
|------|----------|
| **用神** | 以月令地支所藏之神为主，配日干生克关系而定，是全命盘的核心 |
| **格局** | 由月令用神所定的命造类型，分财官印食煞伤劫刃八格及杂格 |
| **相神** | 辅助用神成格的关键字，「伤相甚于伤用」 |
| **成败救应** | 格局因配合而成，因忌神而败，因救应之神而得救的动态过程 |
| **调候** | 在寒热燥湿的气候环境下，以适当五行调和，使格局发挥最大效用 |
| **顺用/逆用** | 吉神（财官印食）顺用生扶，凶神（煞伤劫刃）逆用制化 |

## 阅读价值

- **理论价值**：完整呈现子平命学的逻辑体系，批驳流俗外格迷信，是理解八字正统学问不可绕过的文本。
- **史料价值**：全书引用大量宋元明清历史人物（状元、丞相、将帅）命例，可资命理史研究参考。
- **方法论价值**：反复强调「随时观理」「变化无穷」「不可执一」，具有辩证思维的示范意义。
