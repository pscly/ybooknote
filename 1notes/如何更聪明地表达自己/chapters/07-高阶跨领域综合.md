# 高阶——跨领域综合（Cross-domain Synthesis）

## 要点

1. 跨领域综合是作者最喜欢的框架：将不同领域（心理学、哲学、商业、设计、科技、健康等）的模式或概念引入，支撑核心论证。
2. 结构三段：**问题与放大**（开头共鸣）→ **跨领域综合**（引入跨学科概念）→ **独特流程或解决方案**（自己的思考，非照抄处方）。
3. 跨学科借用让内容产生独特性——用物理学的「熵」解释「深度工作」中分心的运作，市面上大多数深度工作内容做不到这一点。
4. 这个框架天然生成长内容（通讯、书章、YouTube 视频、单口播客），适合深度表达。
5. 写作「积木」（乐高块）帮助填充各小节，避免盯着空白屏幕发呆：痛点、例子、个人故事、统计数据、隐喻、引用、重构、What/How/Why。
6. 「写作就像用观点搭乐高，而观点的形态是可预测的」——理解形态，就能引导自己持续写下去。

跨领域综合是三个框架中最高阶也最能体现个人独特性的一个，其精髓是将广泛兴趣转化为差异化洞见；配合八类写作积木，可系统性地产出深度、原创的长篇内容。
