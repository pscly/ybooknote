# 进阶——金字塔原理（Pyramid Principle）

## 要点

1. 金字塔原理是一种「先给答案」的沟通框架：先抛主观点（关键结论），再用 3～5 个论点支撑，最后提供细节证据（数据、案例、分析）。
2. 与「拖到最后才给答案」的内容相反，金字塔结构让信息更好理解、也更有说服力。
3. 与微型故事框架形成呼应：Hormozi 式的强观点就是金字塔顶端；「连续问 3～5 次'为什么'」是建立支撑论点的方法。
4. 适用场景广泛：通讯、长线程、YouTube 视频的关键点展开，以及播客回答问题。
5. 结构路径：强观点（顶端）→ 为什么×3～5（中层）→ 经历/数据/客户故事（底层）。

## 关键摘录

「先抛出主观点（关键结论或建议）→ 用 3～5 个关键论点支撑它 → 再提供细节证据（数据、案例、分析）。」—— 第06章·金字塔原理  
点评：三层结构简洁清晰，可直接套用于任何长篇写作或口头表达。

「你只需要连续问 3～5 次'为什么'，并给出扎实的推理。」—— 第06章·金字塔原理  
点评：将「为什么」作为构建论证层级的操作性工具，极易执行。

## 小结

金字塔原理将「先给答案」的逻辑结构化，是长篇内容（通讯、视频、播客）的核心骨架，配合微型故事框架可覆盖从短帖到深度长文的全部表达场景。
