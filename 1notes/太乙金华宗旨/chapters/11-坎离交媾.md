# 坎离交媾第十一

## 要点

- **离与坎不是卦象，而是两个不可并存的运动方向**：漏泄精神、动而接物、七窍外走 = 离；收转神识、静而中涵、七窍内返 = 坎。感官的每一个朝向，都在实时投票决定「现在是离还是坎」。
- **五组等式把宇宙直接钉在身体上**：坎离即阴阳 → 阴阳即性命 → 性命即身心 → 身心即神气 → 神气即「真交」。没有中间层可以逃避：你今天下午在微信上「动而接物」，就是在行离卦的「真交」。
- **「真交」与「物质交合」的彻底错位**：一旦精神不随境缘流转，「沉默趺坐」才是更高的真交。读者必须接受：我们一生中绝大多数「亲密」「连接」「重要互动」，在本书的坐标系里其实都是离。
- **离的中间阴爻与坎的中间阳爻**：离卦中间阴 = 逐色随声的空心；坎卦中间阳 = 返闻收见的实心。卦象在这里不是装饰，而是把「外在的空 vs 内在的实」直接画在感官的开关上。
- **没有中立状态**：你不可能「既不离也不坎」。只要七窍在动，就已经在选边。修炼的日常就是把「默认选离」的身体-感官系统，一次次手动拨回坎。

## 关键摘录

「凡漏泄精神，动而交物者，皆离也。凡收转神识，静而中涵者，皆坎也。七窍之外走者为离，七窍之内返者为坎。」—— 第十一章原文
  - 点评：它挑战了「只要我心是好的，行为就没关系」或「我只是正常社交」这类现代安慰。抵抗点一：把「我只是回了个消息、看了一眼短视频」识别为「正在行离卦」，等于承认自己几乎全天都在「漏泄精神」；抵抗点二：接受这个定义后，我们最常用的「我需要保持连接」「我不能太封闭」就会暴露为离的自我辩护。

「坎离即阴阳，阴阳即性命，性命即身心，身心即神照。一自敛息精神，不为境缘流转，那是真交。」—— 第十一章原文
  - 点评：它把「真亲密」「真结合」的定义从「两个人发生什么」彻底移到「一个人的神气是否内敛」。抵抗点：这会让所有依赖「和别人在一起才算活着」的人感到被剥夺——因为按这个标准，绝大多数亲密关系其实是两个离在互相喂养对方的外散。

## 在全书论证链中的作用（辩证位置）

本章把第十章「性光 vs 识光」每时每刻的政变，翻译成感官层面最简单的一组开关：七窍外走 = 离（识光在当家），七窍内返 = 坎（性光有机会回来）。它继承了「用心即识光，放下乃性光」的毫厘之辨，同时给读者提出一个几乎无法拒绝却又几乎不可能持续的要求——把「离转坎」做成日常感官的默认动作，而不是只在打坐时才想起来。这一要求直接为第十二章「周天」和「自然为要」埋下必然：如果连「现在是离还是坎」都不知道，周天就只是识神在身体里画的另一个圈；只有先把离持续转成坎，「自然」才有可能出现。

## 滚动摘要（传给下一章）

到此为止，我们已经把「政权归属」推进到可以每时每刻用感官方向来辨认的程度：外散即离（识光/强藩/魄），内敛即坎（性光/天君/魂）。读者此刻最可能产生的是「那我岂不是要一直监视自己」的恐惧——下一章「周天」必须说明「周天」不是另一个需要用力的工程，而是「离已经转成坎之后，神气自然会发生的升降」，否则前面的所有辨别都会把人逼成一个永远在「转开关」的焦虑主体。坎离的判准，就是把前面所有本体论和认识论，压成一个每天醒来就能用的「我现在又外走了吗？」的简单反问。
