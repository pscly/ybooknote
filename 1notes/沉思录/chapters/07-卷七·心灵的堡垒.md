# 卷七 · 心灵的堡垒

## 要点

1. **熟悉恶的存在**：「这是我时常看到的」——对恶行保持「见怪不怪」的心态，就不会每次都被冲击。历史充斥着同类的事，毫无新鲜之处。
2. **心灵不可攻克**：「不受激情影响的心灵就如同一座堡垒：没有比它更坚实的躲藏之处，所以来这里避难的人是不会受到伤害的。」
3. **哲学信条是活的**：「你的信条是活生生的……内心观念总可以重新激发，这取决于你。」——信条不会自行消亡，只会被放弃或重燃。
4. **悲剧诗歌的用处**：悲剧诗人和哲人引语在本卷大量出现，奥勒留把它们当作随时可取用的「提醒工具」，帮助自己直面现实。
5. **性格的完美境界**：「将每一天都像最后一天那样度过，没有狂热，没有冷漠，没有虚伪。」

## 关键摘录

1. 「退避到内心当中吧。富有理性，起支配作用的心灵的本性，便是满足于做该做的事，享受因此获得的宁静。」——卷七·28，点评：宁静的来源不是外部安静，而是做了该做的事之后的内在满足。

2. 「不受激情影响的心灵就如同一座堡垒：没有比它更坚实的躲藏之处，所以来这里避难的人是不会受到伤害的。」——卷七·48，点评：心灵即要塞，这是全书最有力的防御性比喻。

3. 「性格的完美境界便是：将每一天都像最后一天那样度过，没有狂热，没有冷漠，没有虚伪。」——卷七·69，点评：「最后一天」不是绝望，而是完全的清醒与真实。

4. 「万物都是彼此衔接的，将它们联系在一起的，是一条神圣的纽带。几乎没有一样事物是独立存在的，它们各安其所，共同组成宇宙这一体系。」——卷七·9，点评：万物一体论是斯多葛对人际宽容的宇宙论基础。

5. 「相比舞蹈，生活的技艺更像摔跤，需要站在那里，准备迎接袭来的招数，不要被没有看到的招数摔倒。」——卷七·61，点评：生活是搏击而非编好的舞蹈，随时准备应对未知才是真正的技艺。

## 小结

卷七大量引用诗人与哲学家的语录，奥勒留把这些片段当作心理工具箱——面对恶行、死亡、痛苦时，随时取用；心灵堡垒的比喻则是本卷最强有力的防御宣言。
