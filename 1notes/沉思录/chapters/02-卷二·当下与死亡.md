# 卷二 · 当下与死亡

## 要点

1. **清晨预演**：每日起床第一件事，是预想今天会遇到难相处的人，提前用「他们不懂善恶」来消解愤怒——这是主动的心理免疫。
2. **时间的紧迫性**：「你已经耽搁了许久，众神几度宽限与你，你却坐失良机。」——把每件事当作人生最后一件事来做。
3. **死亡是自然机能**：「死亡不外是自然的一项机能——倘若有谁惧怕自然的机能，那他不过是稚童而已。」
4. **万物速朽**：「肉身的一切皆如河水般逝去，心灵的一切恍如梦幻；人生有如战争，有如游历异乡。」
5. **哲学是唯一护送**：面对人生的短暂与混乱，唯有哲学——维护内心神性、克制享乐与痛苦——能护送我们前行。

## 关键摘录

1. 「清晨首先告诉自己：今天我会见到好管闲事、忘恩负义、好勇斗狠、背信弃义、心肠恶毒、性情乖僻的人。他们蒙受诸般苦恼，是因为他们不懂得明辨善恶。」——卷二·1，点评：不是压抑愤怒，而是在愤怒产生之前用理解将其化解。

2. 「就算你能活三千年，或十倍之久，也要记得，任何人失去的也只是他度过的人生……再长的人生和再短的人生并无不同。」——卷二·14，点评：长寿者与早夭者损失的都只是「此刻」，时间的平等性消解了对死亡的恐惧。

3. 「什么能护送我们前行呢？只有一样东西：哲学。」——卷二·17，点评：全书核心宣言，斯多葛哲学不是书斋学问，而是实践性的人生技艺。

4. 「伤害自己，我的灵魂啊，你是在伤害自己：你不会再有自尊自重的机会了。」——卷二·6，点评：自我损耗不是外部强加的，而是灵魂对自身的背叛。

## 小结

卷二写于战场，奥勒留以当下的紧迫性和死亡的必然性为锤，锻打自己的每一个念头，要求自己在有限的时光里活得完全清醒。
