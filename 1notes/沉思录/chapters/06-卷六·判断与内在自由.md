# 卷六 · 判断与内在自由

## 要点

1. **最好的复仇**：「最好的复仇，就是不要变得跟仇敌一样。」——以提升自身代替报复对方。
2. **事物无法触及心灵**：外物本身是中性的，伤害只来自我们对它们所做的判断，「抛开你的评判，你就抛开了'我受了伤害'的念头」。
3. **宫廷与哲学**：哲学如同生母，宫廷如同继母；应常常回到哲学身边，从她那里获得慰藉，从而能容忍宫廷。
4. **不同级别的价值**：矿石→植物→动物→奴隶→理性的运用→理性本身——最高价值是对心灵理性面的尊重，而非拥有物质。
5. **虔诚地活在当下**：「让你心中的神灵捍卫你的存在……随时做好离去的准备，无需任何忠诚的誓言或他人的见证。」

## 关键摘录

1. 「最好的复仇，就是不要变得跟仇敌一样。」——卷六·6，点评：报复论的终极颠覆：变成仇人的样子，才是真正的失败。

2. 「抛开你的评判，你就抛开了'我受了伤害'的念头；抛开'我受了伤害'的念头，也就抛开了伤害本身。」——卷六·7，点评：伤害的完整链条：外事→判断→感受，斩断第一个环节就斩断了整链。

3. 「如果你从人类的生活中，发现了比正义、真理、克己、勇气更美好的东西……那就全心全意地接纳它……不过倘若你并未找到比心中的神灵更美好的东西，那就别再贪恋他物了。」——卷六·6，点评：开放式的邀请：如果你找到了比美德更好的东西，就去追求；问题是你找不到。

4. 「要始终留意那些因变化而生的事物，要让自己习惯这一想法：整体的本性最爱做的，便是将一种存在形式转变成另一种。」——卷六·36，点评：变化不是损失，而是整体本性最喜欢做的事。

## 小结

卷六的核心是「判断先于伤害」这一认识论洞见：所有的痛苦与伤害都经过了自我判断这道关口，掌握了判断权，就掌握了内在自由。
