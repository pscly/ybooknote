# 第 23 章 · 外部视角与规划谬误

## 要点

- **两种视角的发现**：作者在为以色列教育部设计课程期间，请团队成员对完成时间做出预测，得到"约两年"的乐观估计。随后向课程专家西摩提问：类似团队过去的完成情况如何？西摩的外部视角揭示：约40%的团队以失败告终，成功团队需要7至10年。作者由此区分了**内部视角**（聚焦本团队具体情况）和**外部视角**（参考同类项目的统计分布）。
- **规划谬误（planning fallacy）**：作者与阿莫斯将系统性过度乐观的预测命名为"规划谬误"，其特征是「不切实际地接近最佳状况，可以通过参考类似案例的统计数据进行改进」。现实中的例子极为普遍：爱丁堡苏格兰议会大厦预算从4000万英镑膨胀至4.31亿英镑；全球铁路项目乘客数量被高估106%、成本超支45%；美国厨房改造平均成本超出预算一倍以上。
- **忽略"对未知的无知"**：内部视角的核心错误是"所见即一切"——团队只能想到自己能预见的风险，却无法想象拉姆斯菲尔德所说的"未知的未知"：离婚、疾病、官僚障碍等不可预料的干扰因素。而外部视角的统计数据正是这些未被预见因素累积效应的沉淀。
- **外部视角在竞争中处于劣势**：西摩的统计数据被团队知晓后，仍被迅速遗忘，项目照常推进。原因是外部视角提供的是"乏味的"基础比率，无法与对眼前情况的具体感受竞争——「在与内部视角的竞争中，外部视角没有获胜的可能」，这与第17章中基础比率被个案印象压制的机制完全相同。
- **参考类预测（reference class forecasting）**：傅以斌（牛津大学）将外部视角系统化为可操作流程：①确定适当的参考类；②获取参考类统计数据，得出基线预测；③仅在有特殊理由时，用案例具体信息对基线进行调整。已应用于多国交通基础设施项目评估。
- **沉没成本与非理性坚持**：团队在获知外部视角后本应放弃项目，却因已投入大量精力而选择继续——这是沉没成本谬误的典型表现。作者自我批评道，最终这本教材历时8年才完成，且教育部的热情早已消退，教材从未进入课堂。

## 关键摘录

- 「我们只是将西摩提供的统计数据当作基础比率记录下来，之后就不予理会了。」——本章"偏好内部视角"小节
  - 点评：精准描述了基础比率被忽视的典型模式——不是不知道，而是知道了也不用。

- 「在与内部视角的竞争中，外部视角没有获胜的可能。」——本章"偏好内部视角"小节
  - 点评：一句话总结了人类计划偏差的核心机制，个案的生动感永远压倒统计分布的抽象性。

- 「我称之为非理性坚持：我们那天没有放弃项目，是一种愚蠢的表现。面对选择，我们放弃了理性，却没有放弃那个艰难的项目。」——本章"未通过考验"小节
  - 点评：作者对自身失败的直接批评，将沉没成本谬误与规划谬误紧密勾连，坦诚且有示范意义。

- 「规划者精确执行规划，运作良好的组织会给予奖励；规划者未能预见困难……组织会给予惩罚。」——本章"减轻规划谬误"小节
  - 点评：指出了组织激励结构对规划谬误的加强效应，使偏差从个体认知扩展为制度性问题。

## 在全书论证链中的作用

本章是第三部分"过度自信"的核心实践章节，将第20章的有效性错觉和第21章的算法优势具体化为"项目规划"这一高频决策场景。规划谬误与前几章的"所见即一切"、基础比率忽视形成直接呼应，并为下一章的乐观偏差与过度自信做铺垫——规划谬误不过是更大的乐观偏差综合征的一个典型表现。

## 滚动摘要（传给下一章）

人们在规划项目时系统性采用内部视角，忽略外部视角提供的统计基础比率，导致规划谬误——预测接近最佳状况而非实际分布中位数。即使知道外部统计数据，也因个案感受更生动而将其搁置，并因沉没成本而拒绝放弃已有问题的项目。这一乐观偏差不仅出现在课程规划中，在企业家创业、政府工程、军事决策中同样普遍，下一章将系统梳理乐观主义的双面性及其对资本主义经济的深远影响。
